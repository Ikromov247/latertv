GETTING THERE AND BACK
The Settings button in the guide's top-right corner crossfades to this screen in 160ms. Esc or "Back to guide" crossfades back. The picture stays mounted behind it and the sound keeps playing.
TOGGLES
The whole row is the hit target. ↑ ↓ moves focus and Enter or Space flips the value. Focus is the solid yellow fill. The value is the ON/OFF switch: the filled half is the current value. Changes apply right away, with no Save button. G and C on the TV change the same settings.
API KEY
Save checks the key with one cheap API call. States are not connected, checking, connected (green dot, same green as the OSD) and rejected (red border and the reason). Enter in the field saves. The key is stored locally and shown masked.

Spec notes for implementation
PICTURE ↔ MENU
The player is one element. In the menu it is a 384×216 window at top-left (left 32, top 28, 3px light border). It never unmounts and the video never reloads.
Expand (click the picture, F, or Esc): animate left/top/width/height to the full window and the border to 0 over 420ms, cubic-bezier(0.2, 0.8, 0.2, 1). Menu content fades out over 150ms at the same time.
Return (Esc on the TV): the picture shrinks back over 420ms. The menu fades in over 200ms after a 220ms delay, so it shows up as the picture settles.
Sound keeps playing in the menu. The CRT effect and the green OSD only show at full size. The small window shows only the channel number.
YELLOW HAS TWO JOBS, TWO LOOKS
01 Channel 1Selection is a solid yellow fill. Only one at a time. It is also the keyboard focus.
ADD VIDEOSPrimary buttons are a yellow outline with yellow text. At most one per area.
RenameSecondary buttons are a neutral outline. Destructive ones use red text.
A focused button fills solid yellow, the same as selection.
LIBRARY
Scrolls inside its panel. The guide and the picture stay put.
Order: videos in schedule order, then one collapsed "N can't air" row (expands in place to list the reasons), then the "+ Add videos" tile last.
The tile opens in place into a text box, with status on the left and Cancel / Add videos on the right. When it opens, the panel scrolls so the box's bottom edge shows.
Selecting an empty channel opens the add box automatically.
KEYS IN THE MENU
Esc closes the add box if it's open, otherwise goes back to the TV. F goes back to the TV. On the TV, F still toggles window fullscreen.
↑ ↓ moves through channels in the guide and videos in the library. Tab switches between guide, library and the header. Enter activates. Delete removes the focused video (with an undo toast). ⌘ Enter submits the add box.
SETTINGS
A global button in the top-right corner, set apart from the channel controls. It opens Settings as its own full screen (see 4a). Esc from Settings goes back to the guide.
SCHEDULE
The guide grid shows a 2.5-hour window starting at the half hour before now. The red line marks the current time. Block widths match program length. Blocks cut off at the edges get a 9:20-style time stub.
States Shown in the palette picked in Tweaks. The default frames above cover the upcoming schedule.
